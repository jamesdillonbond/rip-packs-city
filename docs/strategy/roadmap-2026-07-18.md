## Phase 2 — Reduce cost + latency (operator-led, no code)

- **Seed-wallet-refresh cadence** — 4 cohorts × every 6h on cron-job.org. This is simultaneously the **#1 DB-IOPS driver and the #1 Vercel Fluid-memory driver**. Halving to 12h roughly halves both, at the cost of ~2× wallet-data staleness. Single highest-leverage lever available; pure config.
- **Observability sampling down**; GHA-backstop → sole-trigger cutover (see `05-operator-runbook`).
- **Micro instance headroom.** Contention is now the recurring failure mode (connection-pool timeouts, statement timeouts, flaky smoke). Either keep trimming read load or accept an instance bump when revenue justifies it — no infra spend pre-revenue stands.
