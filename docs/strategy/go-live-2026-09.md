## 2. Blockers — must clear before marketing spend

Ordered by how much each one costs a first-time collector.

### B1 — wallet verification has no mechanism (#59) · **needs Trevor's decision**

Pack History and Transaction History gate on verification; verification reads a host that no longer exists. Three options, costed in #59: (a) FCL message signing — excludes Dapper custodial wallets, i.e. most Top Shot users; (b) move the listing challenge to the Top Shot GraphQL host (still answers `searchMomentListings`) — cheapest, Top Shot-only; (c) drop the gate — both pages show public on-chain data, so the gate protected a label, nothing more. **Recommendation: (c) now, (b) later if a "verified" badge earns its keep.** Without a decision, two of the product's tabs are unreachable to every new user.

### B2 — client-side failures are invisible (#34)

Sentry dropped every event since 08-18. Marketing spend brings users whose browsers we have never seen; the only detector of a client crash today is the scheduled `E2E DOM Smoke` badge. **Either pay for Sentry or ship a 30-line `window.onerror` → `/api/telemetry` beacon** (the route exists; anon POST is already open at the proxy). Trevor's call on the money; the beacon is a night-pass-sized ship if he declines.
