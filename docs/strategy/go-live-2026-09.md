## 2. Blockers — must clear before marketing spend

Ordered by how much each one costs a first-time collector.

### B1 — wallet verification has no mechanism (#59) · **needs Trevor's decision**

Pack History and Transaction History gate on verification; verification reads a host that no longer exists.
