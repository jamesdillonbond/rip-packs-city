## 2. Blockers — must clear before marketing spend

Ordered by how much each one costs a first-time collector.

### B1 — wallet verification has no mechanism (#59) · **needs Trevor's decision**

Pack History and Transaction History gate on verification; verification reads a host that no longer exists. Three options, costed in #59: (a) FCL message signing — excludes Dapper custodial wallets, i.e. most Top Shot users; (b) move the listing challenge to the Top Shot GraphQL host (still answers `searchMomentListings`) — cheapest, Top Shot-only; (c) drop the gate — both pages show public on-chain data, so the gate protected a label, nothing more. **Recommendation: (c) now, (b) later if a "verified" badge earns its keep.** Without a decision, two of the product's tabs are unreachable to every new user.

### B2 — client-side failures are invisible (#34)

Sentry dropped every event since 08-18. Marketing spend brings users whose browsers we have never seen; the only detector of a client crash today is the scheduled `E2E DOM Smoke` badge. **Either pay for Sentry or ship a 30-line `window.onerror` → `/api/telemetry` beacon** (the route exists; anon POST is already open at the proxy). Trevor's call on the money; the beacon is a night-pass-sized ship if he declines.

### B3 — Top Shot FMV confidence is sliding (37.3% and falling while the Atlas migration is incomplete)

The 08-03 gate said "accuracy first". Top Shot tripled to 54.5% by 08-13 and has since given back a third of that because the ask feeds are paused. The Atlas ingest is the fix and is already the concurrent track; **the go-live number is 50%+ HIGH/MEDIUM on Top Shot with the Atlas feed live** — not because 50 is magic but because it is where it was before the outage, so it is what the platform demonstrably reaches.

### B4 — cold Collection tab is 15–25 s for a big wallet

7.3 s warm is tolerable; 15–25 s cold is a bounce. The page-1 read (`/api/collection-moments`) is 6.2 s cold and the client then serialises follow-ups. Target **≤ 8 s to first row cold on a 15K wallet** (the honest number: the tile RPC is now 0.3 s, so the remaining cost is page 1 plus the serial chain). Levers, measured not guessed: the `collection-moments` page-1 plan (BUFFERS), and parallelising the client's follow-up fetches.

### B5 — the two operator items that predate everything

#22 (the defeated credential purge — the public branch still carries the pre-purge blob; rotate regardless) and #58 (`OPENSEA_API_KEY`, only if Panini's OpenSea plane is chosen). Neither is code.

What is missing is the product plane. "Live" is three switches (`*_PUBLIC` → already true since 07-31; `published: true` in `lib/collections.ts`; `collections.is_active` in Postgres) and the checklist is in [docs/audits/audit-2026-09-06-candy-and-panini-go-live-readiness.md](../audits/audit-2026-09-06-candy-and-panini-go-live-readiness.md) — summarised:

## 5. Panini → LIVE — blocked on one product decision, not on engineering

Two Panini data planes exist and the collection registry describes a third:

- **WC Prizm plane** (`nft.paniniamerica.net`, private Sawtooth chain, no wallet concept): 4,910 `panini_editions`, 46K FMV rows, 36.2% trustworthy coverage, the squeeze board — real data, in side tables, **0 rows in the shared schema**.
- **OpenSea bridge plane** (`paniniblockchain`, ERC-721, mostly non-sports): what `lib/collections.ts` and the static `/panini-blockchain/overview` + `/sniper` pages describe — and both 502 on every load because `OPENSEA_API_KEY` is unset (#58). No editions/FMV pipeline exists for it at all.

`is_active=true` on a row with 0 `editions` puts a Panini row of zeros in every cross-collection rollup — the fabricated-number shape. So: **P0 (Trevor): which Panini is the collection?** If WC Prizm: bridge the side tables into `editions`/`fmv_snapshots` (1–2 weeks) with the 36.2% coverage disclosure travelling to every surface. If OpenSea: set the key, delete or source the hardcoded `PANINI_NEWS`, and accept that pricing is net-new (1–2 weeks). **Recommendation: WC Prizm — it is the plane with data, and the squeeze board already earns its keep; ship Candy first while Trevor decides.**
