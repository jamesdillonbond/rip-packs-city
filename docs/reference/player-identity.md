# Player identity, name variations and the stats feed

Written 2026-09-25 (PT) at the close of the crosswalk thread (#139; batches 44–62 in `docs/overnight/ledger.md`). Every number here is a dated sample — re-derive before quoting. The canonical rule lives in CLAUDE.md (Concierge rule 2): **a NAME is not a PERSON; a team label is not a FRANCHISE.**

## The model

A collector types a label; the catalog holds people. Between them sit five kinds of variation, and RPC now carries data for each:

| variation | example | where it lives |
|---|---|---|
| a second spelling of one person | Joseph / Joe Flacco, Stephen / Steph Curry, Kenneth / Kenny Gainwell | `player_name_aliases` (`alias_slug` → `player_id`; the URL 308s, the name writers never re-mint it) |
| the league's spelling vs RPC's | nflverse "Mike Vick" / All Day "Michael Vick"; "Deebo Samuel Sr." | `player_identities.display_name` (the league's) beside `players.name` (RPC's); `resolve_player_name` reports `league_name_differs` |
| a name change | Robby Anderson → Robbie Chosen (2022), the Jaguars' Josh Allen → Josh Hines-Allen (2024), Enes Kanter → Enes Freedom, Skylar Diggins-Smith → Skylar Diggins, Betnijah Laney → Laney-Hamilton, Megan Gustafson → Megan DiLeo | `player_relations` (`relation = 'name_change'`, `name` = the other name) **and** an alias for the other spelling |
| a father and son (or an unrelated namesake) | Marvin Harrison / Jr., Gary Payton / II, Tim Hardaway / Jr., Larry Nance / Jr., Ron Harper / Jr., Glenn Robinson / III, Antoine Winfield / Jr., Asante Samuel / Jr., Joey Porter / Jr.; Byron Murphy Jr. (CB) vs Byron Murphy II (DT) — unrelated | `player_relations` (`parent_of`, `namesake`), hand-curated, public record only |
| a franchise under several labels | Las Vegas / Oakland / Los Angeles Raiders; Washington Commanders / Football Team; SuperSonics → Thunder, Bullets → Wizards, Bobcats → Hornets, "Los Angeles Clippers" → LA Clippers; San Antonio Stars → Aces | `league_team_abbr(p_league)` = `teams_master` + a VALUES list of historic names (`nfl`, `nba`, `wnba`); **every team read covers the whole franchise** (batch 62: `team_franchise_slugs`) and a historic label's URL 308s to the current name |

Underneath: **`player_identities`** is the crosswalk — `league` (`nba` for Top Shot, `nfl` for All Day) + `league_player_id` (NBA person id / NFL GSIS id), `player_id` → the RPC row, the league's `display_name`, seasons and latest team (nflverse for NFL; derived from the player's own ESPN stat lines for the NBA half), `espn_id` + `espn_league` (`nba` | `wnba` | `nfl`), `matched_by` (how the row was keyed: `name`, `suffix+team`, `hand:2026-09-25`, `resolver`…). `base_slug` is the name slug with the generational suffix removed. Every name writer resolves through it where the identity is feed-backed: the daily linker (`link_editions_to_players_by_name`, `rpc-link-editions-to-players` 2:55 AM PT), the seeder (`ensure_players_from_edition_names`) and wallet-search's `resolve_canonical_player`.

## The resolvers (service_role only, both pinned)

`resolve_player_name(collection_id, name)` → `one` | `ambiguous` | `none`. Arms in order: exact spelling → alias → the league's spelling → a recorded former name → the base name with the suffix dropped ("X Sr." names the unsuffixed row) → a partial that matches exactly one player. `one` carries `player` (id, name, the SITE's slug — a trailing "." keeps its dash, `/player/marvin-harrison-jr-` — team, edition count, **`labels`**: every `editions.player_name` the person's editions carry), `aliases`, `identity`, `relations` (as seen from this player: `parent_of` / `child_of` / `unrelated_namesake` / `also_known_as`), `namesakes` (every other row sharing the base name, each described the same way, plus any row whose former name is the query) and a `note` when namesakes exist. `ambiguous` carries `candidates` in the same shape.

`resolve_team_name(collection_id, name)` → `one` | `ambiguous` | `none`. Every team label of the collection is keyed to a franchise (`map:<league>:<abbr>` via `league_team_abbr` — nfl; nba **and** wnba for Top Shot, namespaced so the Mystics' WAS never folds into the Wizards' — else `tm:<league>:<abbr>`, else the label itself), a matched franchise expands to **all** its labels, `primary_name` is the `teams_master` name (else the most-minted label), `historic_names` carry edition counts. An exactly-typed primary name decides among several franchises.

**The team reads (batch 62, Trevor 09-25: "historic era should be included in that franchise").** `team_franchise_slugs(collection_id, team_slug)` → the site slugs of every label of the franchise the slug names, keyed from the registries only (`league_team_abbr`, else `teams_master`, else the slug alone; accent-tolerant) — registry-keyed so it costs ~10 ms and can sit in an index condition; `team_franchise_primary_name(collection_id, team_slug)` → the `teams_master` name of the franchise, else its most-minted label, else NULL; `team_historic_slugs(collection_id)` → every label whose franchise has a different primary name. `get_team_detail` and the seven section RPCs (`get_team_players`, `_top_editions`, `_activity`, `_sets`, `_squeeze`, `_checklist`, `_checklist_progress`) match `slug = ANY (ARRAY(SELECT unnest(team_franchise_slugs(…))))` — ⚠ the `ARRAY(SELECT …)` form is an InitPlan, so the helper runs ONCE per statement; a bare `= ANY (fn(…))` or a SQL-language helper that inlines re-runs it per scanned row (the first apply hit a 57014 exactly that way). `get_team_detail.team_name` is the primary name, so `/team/oakland-raiders` 308s to `/team/las-vegas-raiders` through the team layout's canonical-slug redirect, the franchise hub (`get_franchise_hub` → `get_team_detail` per collection) sums every era, and the sitemap drops the historic slugs (`lib/sitemap-data.ts`, a failed read fails the segment). All three helpers are pinned (`supabase/tests/team_franchise_slugs.sql`).

## How the concierge uses them

`app/api/support-chat/route.ts` — `executeTool` resolves the typed player name **once** for the six label-keyed tools (`search_live_deals`, `search_catalog_deals`, `get_edition_listings`, `search_serial_deals`, `get_special_serial_owners`, `get_badge_info`): `player_name IN (labels)` or `player_id` where the table has it, candidates on `ambiguous` (nothing searched), the tool's own ILIKE when the read is `none` or **`unavailable`** (the fourth state, `lib/concierge/player-identity.ts` — a failed read is never "no such player"). `get_player_editions` / `get_fmv` / `search_catalog_deals` resolve and attach `player_identity`; `resolve_player_name` is also a tool ("who is X / are they related"). `get_team_intel` resolves to the franchise, reads the primary name and attaches `franchise` (historic labels with counts; since batch 62 the note says those eras are INCLUDED in the reads, never that they sit elsewhere). Prompt sections: **Names are not people**, **Teams are franchises**. Pinnacle (characters) and `search_across_collections` are not scoped.

## The stats feed (ESPN, public JSON, a GitHub Actions runner)

`player_season_stats` ← `scripts/sync-player-stats.mjs` → Bearer route `/api/cron/player-stats-sync` (every 6 h at :23 UTC; GitHub sheds ticks often — dispatch by hand with `POST /actions/workflows/367381062/dispatches`). Per player: `site.web.api.espn.com/apis/common/v3/sports/{football/nfl | basketball/nba | basketball/wnba}/athletes/<espn_id>/stats`. Facts measured 2026-09-25:

- **Search is `/apis/search/v2?query=&type=player`**, not the v3 `common/v3/search` — v3 is active-only and returns no WNBA; v2 returns retired players, carries the athlete id in `uid` (`s:40~l:46~a:662`) and the league in `defaultLeagueSlug`.
- ESPN keeps **duplicate athlete entries**: a G League affiliate copy (`nba-development` — Fultz on "Raptors 905" with the same id the NBA path serves), a phantom with no team, and a player now abroad filed under `fiba` / `nbl` with the same id (Šarić, Vanloo). The runner settles a same-name set by a **stats probe** — the one candidate whose stats page has seasons — and leaves two real players ambiguous (Dee Brown; Courtney Williams ×2 in the WNBA). College leagues are never candidates.
- A stats page of `{ filters:[…] }` with **no `categories`** is ESPN's "no stat lines" (an offensive lineman) — an answered empty, zero rows; a payload with neither is a failed read. A traded season is one line per team plus a "<year> Totals" line (`is_total`, `team_slug ''`).
- One failed fetch or search in 300–400 is noted, not a failed run (< 5 %); a failed search leaves its target for the next tick; a 500 on a retired player's id (5 as of 7:35 PM PT) is retried every tick, harmlessly.
- `get_player_season_stats(player_id, seasons)` → NULL (no identity / no espn_id — the page renders nothing) | rows `[]` ("no season stats from the feed yet") | rows; it returns `espn_league` so a WNBA season is labelled by its calendar year. The section lives on every Top Shot / All Day player page.
- State at close (7:35 PM PT 09-25): Top Shot 1,288 / 1,317 identities keyed (1,015 NBA + 273 WNBA), All Day every person nflverse knows; 60,725 lines over 2,605 players. The 29 unkeyed are ESPN's gaps (1980s–90s players; Patty Mills' fiba id serves no NBA lines).

## Per-game box scores and performance → market cap (2026-11-08)

Trevor asked whether player performance can be tied to moments, cards and market caps ("Do all of it"). Three migrations, all live and committed: `20261108174208` (lane + view), `20261108181838` (LaLiga + Golazos crosswalk), `20261108182316` (Panini crosswalk). Numbers below are dated samples.

- **Lane (database pg_net, not the GitHub runner).** `espn_gamelog_dispatch()` (pg_cron `4,14,24,34,44,54`) → `espn_gamelog_drain()` (`7,17,27,37,47,57`), pipeline `espn-game-logs`. One `site.api.espn.com/apis/site/v2/sports/<path>/summary?event=<id>` per completed game covers every player; leagues are rows of `espn_leagues` (league, ESPN path, sport, backfill floor — `20261108183002`): NBA, WNBA, NFL, MLB, and soccer LaLiga, Premier League, Serie A, Bundesliga, Ligue 1, MLS, Liga Portugal, Eredivisie. **Adding a league = one `espn_leagues` row + one `espn_gamelog_backfill_state` row** (probe its scoreboard from pg_net first; the Saudi Pro League answered 0 events 11-08). Scoreboards for yesterday + today twice an hour; a per-league backfill cursor (`espn_gamelog_backfill_state`, to 2026-10-01; LaLiga to 2026-08-14). `espn_box_rows(league, body)` parses both summary shapes (`boxscore.players[].statistics[]` with `keys[]`; soccer `rosters[].roster[].stats[]`). A summary for a game not yet final resets the event, never ingests.
- **Tables.** `player_game_stats` (one row per player × game × box group; `stats` = ESPN key → displayed value; `fantasy_points` = that group's contribution: DK classic for NBA/WNBA, half-PPR for NFL, an RPC soccer index for LaLiga, none for MLB), `espn_game_events`, `espn_athletes` (every athlete a box score names, with ESPN's spellings), `espn_gamelog_requests`. All RLS on, no anon/authenticated grant.
- **`player_game_market_moves`** (`security_invoker=on`): one row per player-game per collection carrying that person in that sport — fantasy points, season-to-date average before the game, and `market_cap_daily` player mcap + `collector_held` at d−1 / d+1 / d+3. ⚠ **Filter `held_before = held_d1` before reading a move as price** — a mint or burn moves mcap with no trade. ⚠ **No single game is evidence:** Luka 11-04 65.75 fp → Top Shot mcap −11.9 % d+1; 11-06 69.75 fp → +4.9 %.
- **Crosswalks kept OUT of `player_identities` on purpose** — that table is read by the name writers (`link_editions_to_players_by_name`, `ensure_players_from_edition_names`, `resolve_canonical_player`, `resolve_player_identity`), so a row there would let ESPN's spelling reach a collection's names. Instead: `golazos_espn_crosswalk` (refreshed by the drain when a LaLiga box lands; a Golazos market-cap key matches when exactly one LaLiga athlete seen in a box score carries that slug) and `panini_espn_crosswalk` (daily `rpc-panini-espn-crosswalk`; sport from `panini_products.last_grid_sport` as `get_player_hub` derives it; exactly one id in the sport, AND the suffix-stripped slug must not reach a second id — `family_ambiguous` holds back Gary Payton / II, Tim Hardaway, Robert Griffin III and five more). First run: 1,970 Panini keys ($14.1M of $14.4M basketball, $7.3M of $7.8M football player mcap); 14 random matches checked by hand, all the right person.
- **Not linked:** UFC (its market is closed — `market_cap_*` reads NULL, nothing to join) and Panini racing. Panini soccer (World Cup cards) links as the seven non-Spanish leagues backfill — 14 of 2,109 keys before them; national-team players outside those leagues stay unlinked.
- **Season level (read, not shipped, 11-08):** rank correlation of 2025–26 production with player market cap 0.73 Top Shot NBA (n 451), 0.81 WNBA (142), 0.69 All Day half-PPR (300); supply 0.51 and average price per held moment 0.29 (NBA) — market cap tracks how many moments exist more than what each sells for. ⚠ `player_season_stats` traded seasons: pick `DISTINCT ON (espn_id, season[, category]) ORDER BY is_total DESC`; `coalesce(is_total, true)` keeps only the traded players. ⚠ `market_cap_current` carries an `is_primary=false` alias row per accented name — filter `is_primary`.

## Spelling variants vs aliases — fold the first, crosswalk the second (2026-11-01)

`wallet_moments_cache.player_name` (and other denormalised name copies) spell one player several ways (#221: 9,842 Top Shot / 2,286 All Day rows disagree with `editions`). Two different problems:

- **Spelling variants** — accents (Dončić/Doncic), case (Demar/DeMar), punctuation (O.G./OG), a trailing generational suffix (Jimmy Butler III/Jimmy Butler). ONE normaliser handles all four: `public._norm_player` (pinned, `supabase/tests/norm_player.sql`) and its TypeScript mirror `playerNameKey` in `lib/filter-match.ts` (parity test replays the SQL pin's cases). - **Aliases** — Rob/Robert Dillingham, nicknames, renames, father/son: NOT a normalisation problem. They belong in the crosswalk (`resolve_player_name`, `player_relations`; rule 2), and folding must never merge them (the dropdown test's control keeps Rob and Robert apart).
