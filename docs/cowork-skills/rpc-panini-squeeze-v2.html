Pack reality + EV — WC Prizm packs

Actual EV = supply-weighted expected pull value (chase-inclusive); Typical pull = median-based, what a normal pack returns; Net edge = Actual EV − pack cost. Slot odds are the published pack contents (verified 2026-07-18): Hobby = 2 silver + base parallel + other + bonus, insert 7-in-20. FOTL = Hobby + one guaranteed FOTL-exclusive parallel (#/11–1/1: Aguila/Maple Leaf/Old Glory/Nebula), excluded from Hobby. Families are weighted by copies still in packs — the remaining pool you actually draw from — so EV tracks as the best chases deplete. At current prices FOTL rips +EV; Hobby does not (≈ fair).
