Security. Every points mutation is written only by service_role or the SECURITY DEFINER functions (award_points / redeem_shop_item / fulfill_redemption / admin_adjust_points / draw_raffle). RLS is on for all rewards tables; anon and authenticated are SELECT-only — no write path exists.
Delivery. Pro + cosmetics deliver instantly at redeem (Pro → pro_users, cosmetic → user_cosmetics + equipped). Moments + swag stay in the queue for manual fulfillment.
To grant/adjust manually: admin_adjust_points(user_id, delta, status_delta, reason, 'owner'). To draw a raffle: draw_raffle(shop_item_id, 'owner') (raffle items are held inactive until official rules ship).
