What this is. The community set-challenge-tracker shows only completions ÷ allocation → packs per completer. This board adds RPC's pricing and turns it into an ROI call. Exp. net = reward/pack × packs/user − cost-to-complete — the airdrop-adjusted answer to "is completing this worth it", the way the Top Shot blog frames set rewards (fewer completions → more bonus packs each). A green Exp. net means the expected packs alone cover the completion cost; you also keep every moment you bought.
Source. get_active_challenges over challenges + challenge_slots + challenge_slot_editions and latest FMV. Reward/pack = the completion pack's value: the pack's own recent secondary-sale median (≥3 sales/90d — the true market price), falling back to drop-pool moment FMV only for thin-market packs; blank where the pack doesn't trade (7 packs). Measured 2026-07-14, the old per-slot pool method understated real pack value 2–7×, so reward now uses market prices wherever the pack is liquid.
