# RPC deep-audit findings register

Persistent across monthly deep audits. **Purpose: never re-derive a settled question.**

How to use it: at the start of each deep audit, run only the one-line probe for each `VERIFIED-CLEAN` row. If it still returns the expected value, stamp the date and move on — do NOT re-audit that area. If a probe fails, that becomes a finding and earns a full investigation. Re-measure each `OPEN` item's evidence number and record whether it grew, shrank, or resolved.

⚠ **THE CHEAP CHECKS, cumulative through run 3.**
1. **Grep before you measure** — the target file's own comments, plus `docs/handoff-*.md`, `docs/audits/*.md`, and **all** of `docs/overnight/inbox/*`. Do NOT narrow to ledger-referenced handoffs; that is exactly how D28 was filed.
2. **Read one raw `pipeline_runs.extra` payload** before calling any pipeline dead, inert, stalled or broken. The `rows_found`/`rows_written` pair cannot distinguish "caught up" from "failing silently".
3. **Bound every rate by the DEPLOY, not the clock.** A rate measured across a fix is not a rate.
4. **When a threshold is allegedly exceeded and nothing is failing, doubt the comparison.**
5. **A watchlist / suppression justification is a claim with an expiry date.** Sweep the class, not the row.
6. **`check_anon_write_surface()` is blind to a route holding the SERVICE-ROLE key** — it tests the anon DB role.
7. **A cost estimate is not a measurement and one warm timing is not a cost.** Quote buffers.
8. **(run 3) Read code from `origin/main`, never a stale working tree, and cite the SYMBOL not the line number.** Run 3's clone was 134 commits behind; eleven OPEN items were already fixed inside those commits and a working-tree sweep would have re-filed all of them.
9. **(run 3) Diff the SET, not the count.** `cron.job` moved 85 → 93, which reads as +8 and is **+10 added, −2 removed**. The two removed jobs are now unnameable because no 08-15 snapshot exists.
10. **(run 3) A guard's declared scope is a measurement — take its positive control.** Re-implement the guard's own detector and run it on its declared roots first; if it returns 0 there, the guard is honest and the finding is about its SCOPE, not its logic.
